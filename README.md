# ISTEA Time

Proyecto web de e-commerce desarrollado para la materia **Laboratorio de Aplicaciones Web Cliente**.

## Descripción

ISTEA Time es una tienda online orientada a la exhibición y compra de relojes. La aplicación permite visualizar productos, explorar un catálogo, consultar el detalle de cada producto y gestionar un carrito de compras con persistencia en `LocalStorage`.

## Funcionalidades

- Página principal con secciones destacadas
- Catálogo de productos con buscador
- Cards dinámicas generadas con JavaScript
- Modal con detalle de producto
- Carrito de compras con:
  - agregado de productos
  - modificación de cantidades
  - eliminación de productos
  - cálculo de total
  - persistencia en `LocalStorage`
  - finalización de compra
- Diseño responsive

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- Fetch API
- LocalStorage
